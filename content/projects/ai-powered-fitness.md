AI-Powered Fitness is a modern, full-stack health application designed to democratize personal training. By leveraging Large Language Models (LLMs), the platform generates highly personalized nutrition and workout roadmaps based on a user's unique body metrics (BMI), fitness goals, and available equipment.

### Key Features

* **For Users**: Personalized Fitness Profiling, Instant BMI Calculation, AI-Generated Custom Diet Plans, Tailored Workout Routines, PDF Export for offline access, and 24/7 AI Chatbot support.
* **Intelligent Services**: Real-time health advice via Groq AI, location-based gym and yoga studio discovery using Google Maps integration, and secure progress tracking.

### Tech Stack Highlights

* **Frontend**: React 18, TypeScript, Vite, Tailwind CSS (Glassmorphism UI), Lucide React, jsPDF.
* **Backend & Integration**: Supabase (PostgreSQL & Auth), Groq SDK (Llama 3), Google Generative AI (Gemini Pro).

For detailed information on features, installation, usage, and project structure, please visit the [AI-Powered Fitness GitHub Repository](https://github.com/Prajwal-banakar/Ai-powered-Fitness).
